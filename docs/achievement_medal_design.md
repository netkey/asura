# 成就勋章系统设计文档

## 概述

Asura 成就系统目前已有 19 枚成就的基础逻辑（自动检查、金币奖励、站内通知），本次设计围绕**看得见、想收集**的目标，不做复杂体系和新增服务端存储，只做展示层。

## 勋章分类

> 分类仅为展示归类，服务端不存储分类 ID。

| 分类 | 勋章 |
|------|------|
| 🗡️ **战斗中** (Battle) | 破阵斩将、势如破竹、锐不可当、战无不胜、君临天下、揭竿而起、孤注一掷 |
| 🌱 **成长路** (Growth) | 初涉江湖、身经百战、沙场老将、戎马半生、千战不殆、初出茅庐、擂台初鸣、身份初显 |
| 🏆 **排位** (Ranked) | 崭露头角、声名大噪 |
| ⭐ **精通** (Mastery) | {英雄}专精、{英雄}大师 |

## 客户端数据接口

客户端展示所需数据全部来自现有 RPC，**服务端无需改动**：

| 数据 | 来源 RPC | 说明 |
|------|---------|------|
| 勋章列表 | `get_achievement_list` | 返回全部 19 个定义 + 玩家解锁状态 |
| 已解锁列表 | `get_my_achievements` | 返回 `{ach_id: {unlocked_at}}` |
| 玩家资料 | `get_my_stats` | 可展示段位、对局数等关联信息 |

## 奖励体系

维持现有金币奖励不变，不做额外奖励类型（不做头像框、称号等）。
