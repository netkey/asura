# 客户端成就勋章展示方案

## 功能一：勋章墙（Medal Wall）

### 位置
主界面 → 个人资料 → 勋章页

### 布局
- 网格布局，每行 4 枚勋章
- **已解锁**：彩色勋章图标 + 勋章名称
- **未解锁**：灰色描边占位 + "???" + 解锁条件文本

### 勋章图标设计建议
- 每个勋章一个 icon，风格统一（圆徽章/六边形/盾牌形）
- 图标内容与勋章名关联（如"破阵斩将"=交叉弯刀、"君临天下"=王冠）
- 已解锁：金边/彩色；未解锁：灰边/半透明
- 精通勋章使用英雄头像 + 星星标识（1星=专精，2星=大师）

### 交互
- 点击勋章 → 弹出详情浮窗
- 详情浮窗内容：
  - 勋章名称
  - 解锁条件描述
  - 金币奖励数额
  - 解锁时间（已解锁）/ "未解锁"（未解锁）
  - 精通勋章额外显示已解锁英雄列表

### 数据来源
```json
// get_achievement_list 返回示例
{
  "achievements": [
    {"id": "first_win", "name": "初出茅庐", "gold": 100,
     "unlocked": true, "unlocked_at": 1746000000},
    {"id": "streak_10", "name": "战无不胜", "gold": 500,
     "unlocked": false},
    {"id": "hero_mastery_10", "name": "%s专精", "gold": 150,
     "unlocked": true, "heroes": ["aladdin", "sinbad"]}
  ]
}
```

### 顶部统计
勋章墙顶端显示统计数据条：
- 已解锁：**8** / **19**（静态勋章进度）
- 精通勋章额外计数：**2/30** 专精 · **1/30** 大师
- 总计获得金币：**1,280**

## 功能二：资料页勋章展示

### 位置
个人资料页（大厅可见）

### 展示内容
- **成就模块**：已解锁勋章数量（"勋章 8/19"）
- **自选展示位**：玩家可选 1~3 枚勋章展示在资料页
  - 展示数据从 `get_my_achievements` 中取 `unlocked` 列表，客户端本地筛选
  - 选择界面复用勋章墙的网格 UI，已解锁的可勾选
  - 自选结果存储在客户端本地（SharedPrefs/PlayerPrefs），无需服务端接口

### 视觉规格
- 勋章展示图大小为勋章墙版本的 1.5 倍
- 悬停/点击可查看该勋章名称

## 功能三：解锁弹窗

### 触发时机
对局结算结束后，如有新成就解锁，立即弹窗。

### 判断方式
客户端在结算后调用 `get_my_achievements`，与本地缓存的已解锁列表比对，差异即为新解锁项。

### 弹窗内容
- 勋章名称 + 图标（同勋章墙风格）
- "解锁成就！" 标题
- 金币奖励（"+100" 金色数字）
- "太棒了！" 等鼓励文案
- **确定** 按钮

### 多枚同时解锁
如一场对局解锁多枚（例如首胜 + 连胜 + 精通），展示翻页式弹窗，可左右滑动查看。

## 数据对接流程

```
[客户端启动]
     ↓
1. 调 get_my_achievements → 缓存已解锁列表
2. 调 get_achievement_list → 缓存完整勋章数据（含条件/奖励）
     ↓
[勋章墙页]
     ↓
3. 按分类渲染勋章网格（取缓存数据）
4. 点击勋章 → 用缓存数据展示详情浮窗
     ↓
[对局结束]
     ↓
5. 调 get_my_achievements
6. 对比缓存 → 发现有新解锁项
7. 弹出解锁弹窗
8. 更新本地缓存
     ↓
[资料页]
     ↓
9. 取已解锁数 + 自选列表 → 渲染展示位
```
